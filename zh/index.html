ModelAny 是什么？

ModelAny 是免费的 Chrome 与 Edge 浏览器扩展。输入一次问题，即可同时发给 ChatGPT、DeepSeek、Kimi、豆包等最多 11 个 AI 官网，并排对比答案。它还能把对话导出为 Markdown / Word / PDF，带着上下文换模型继续聊，总结视频与网页，并提供只存在本机的记忆库。

真的完全免费吗？

是的。ModelAny 不收费、不卖积分、没有内购。回答由各 AI 官网提供，按它们自己的规则计算额度：免费账号用免费额度，会员账号继续用会员额度。

需要 API Key 吗？

不需要。ModelAny 直接使用你在浏览器里已登录的官方网站：打开网页、填入问题、点击发送，和你手动操作一样。

支持哪些 AI？

目前支持 11 个 AI 官网：ChatGPT、Claude、Gemini、DeepSeek、Grok、Kimi、通义千问、豆包、智谱 GLM、腾讯元宝、文小言。视频字幕支持 YouTube 与哔哩哔哩，网页正文支持任意普通网页。

我的对话会被上传吗？

不会。ModelAny 没有自己的服务器。问题只发到你选择的 AI 官网；草稿、历史与记忆库都保存在你的浏览器里，导出文件也在本地生成。

会不会导致账号被封？

ModelAny 只是替你完成「打开网页、粘贴问题、点击发送」这几个动作，每次都由你主动触发；不做批量请求，也不绕过额度、验证码或安全机制。你在各 AI 网站上的使用仍受其自身条款约束。

如何把 AI 对话导出为 PDF 或 Word？

在 ChatGPT、DeepSeek、Kimi 等支持的站点打开对话，点击页面右侧的 ModelAny 小标签，选择 Markdown、Word 或 PDF。文件在浏览器里生成，直接保存到你的电脑。分步教程

如何用 AI 总结 B 站或 YouTube 视频？

打开带字幕的视频页，点击 ModelAny 图标 →「附上字幕」。ModelAny 会读取带时间点的字幕，你可点「总结要点」或「章节时间线」后发送给任意 AI。视频本身需要有字幕或自动字幕。查看教程

某个 AI 次数用完了怎么办？

使用「换个模型继续」。在对话页打开 ModelAny 工具条，点另一个模型（如 DeepSeek、Kimi、Claude）。ModelAny 会把当前对话整理成上下文，在新标签页里继续聊，不用从头解释。

支持哪些浏览器？

已上架 Chrome 网上应用店与 Microsoft Edge 加载项。其他可从 Chrome 商店安装扩展的 Chromium 浏览器通常也可使用。暂不支持 Firefox、Safari 与手机浏览器。

源码可以查看吗？

可以。源码公开在 GitHub，便于审查数据处理方式。采用专有许可证：可以阅读与审计，但不得重新打包或分发。
