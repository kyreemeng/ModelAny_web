导出 AI 对话为 PDF、Word 或 Markdown

把当前 AI 对话保存为本地文档

在支持的 AI 网站上，页面右侧会出现 ModelAny 小标签。点开后可将当前对话导出为 Markdown、Word（.docx）或 PDF，也可复制为 Markdown。文件在浏览器本地生成并下载，不会上传到 ModelAny 自有服务器。

ChatGPT、DeepSeek、Kimi、豆包、通义千问、智谱 GLM、腾讯元宝、文小言，以及 Claude、Gemini、Grok 等站点使用同一套工具条。

导出步骤

  1. 在支持的 AI 网站打开一段对话
  2. 点击页面右侧的 ModelAny 小标签
  3. 选择 Markdown、Word、PDF，或「复制为 Markdown」
  4. 按浏览器提示保存文件，或粘贴剪贴板内容

格式怎么选

Markdown 适合笔记、仓库与纯文本工具；Word 适合协作修改；PDF 适合固定版式与打印；复制为 Markdown 则便于贴进 Notion、Obsidian 或编辑器。

隐私说明

仅在你点击导出后，读取当前页面上已渲染的对话，并在本地生成文件。清除该扩展的浏览器数据或卸载扩展，会一并清除其本地存储。

实用建议

  • 长对话离开前先导出，避免之后难以找回
  • 若还要全文检索，可同时「存入记忆库」
  • 若看不到小标签，刷新页面并确认扩展已对该站点启用

安装入口

请从与当前浏览器对应的官方商店安装。草稿、设置、历史与记忆库留在本机；提示词只发送到你勾选的 AI 官网。

常见问题

能导出 ChatGPT 付费版对话吗？

可以，只要对话在浏览器里的 ChatGPT 网页中打开。ModelAny 导出的是页面上可见的内容，并不调用 OpenAI 官方导出接口。

图片或上传的文件会一并导出吗？

以文本轮次为主。图片与附件是否出现，取决于页面 DOM 能否提供对应内容，部分情况会省略或仅保留占位说明。

PDF 是在服务器上生成的吗？

不是。PDF、Word 与 Markdown 均在浏览器本地生成并下载。

在 AI 页面直接导出对话

安装 ModelAny 后，打开任意支持的对话页即可使用右侧工具条。免费，无需 API Key。 Chrome 网上应用店 · Microsoft Edge Add-ons
