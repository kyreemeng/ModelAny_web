AI 浏览器插件：同一提示词对比多个模型

装在 Chrome / Edge 上，服务你已在用的 AI 官网

ModelAny 通过 Chrome 网上应用店或 Microsoft Edge 加载项安装。它不是又一个聊天机器人，而是叠加在 ChatGPT、DeepSeek、Kimi、豆包等网页版之上：同一提示词发给多个站点、导出对话、附上视频字幕、换模型继续，以及本地记忆库。

没有 ModelAny 账号、积分包或 API Key。各站点免费或付费套餐仍按原样使用。草稿与历史留在浏览器；提示词只发往你勾选的官网。

安装

  1. 打开 Chrome 网上应用店或 Edge 加载项中的 ModelAny 页面
  2. 添加扩展，并固定到工具栏
  3. 登录你常用的 AI 网站
  4. 按 Ctrl+Shift+Y（Mac 为 ⌘+Shift+Y）完成第一次发送

装好之后能做什么

  • 同题对比：一次输入，发送到多个官网，并排阅读答案
  • 导出与保存：把任意支持的对话导出为 PDF / Word / Markdown，或存入本地记忆库
  • 视频总结：在 B 站或 YouTube 播放页附上字幕，发给你的模型总结要点与章节
  • 换个模型继续：达到限额或想要第二意见时，带着上下文转到另一个官网

什么时候适合用扩展

若工作已在浏览器里完成、又不想在多个标签页重复粘贴同一段需求，扩展很合适。若你需要服务端编排或统一的厂商 API 账单，应直接使用该厂商 API——ModelAny 有意停留在网页操作路径。

安装入口

请从与当前浏览器对应的官方商店安装。草稿、设置、历史与记忆库留在本机；提示词只发送到你勾选的 AI 官网。

常见问题

ModelAny 收费吗？

扩展本身免费。各 AI 网站若提供付费套餐，额度与模型仍由该网站计费。

Edge 能用吗？

能。从 Microsoft Edge 加载项安装即可，支持站点上的行为与 Chrome 版一致。

把 ModelAny 加到浏览器

可在 Chrome 网上应用店与 Microsoft Edge 加载项获取。本地优先；提示词路径上没有 ModelAny 服务器。 Chrome 网上应用店 · Microsoft Edge Add-ons
